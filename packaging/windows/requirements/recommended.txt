# Agent Friday - Windows installer :: RECOMMENDED tier
#
# Friday starts and works without these; noticeably less of her works.
# A failure here is a warning in the maintainer's report and a calm sentence for
# her. It is never a stop.
#
# Verified on Windows 11 in embeddable CPython 3.12.10: resolves
# and installs with --only-binary=:all: and every module imports. Zero wheels
# built from source. The heaviest thing in here is spacy's tree (blis, thinc,
# numpy) pulled in by presidio, all of which ship cp312 win_amd64 wheels.

# --- Tier-1 local voice: her ears and her mouth, CPU only, no torch --------
faster-whisper>=1.0
piper-tts>=1.2
onnxruntime>=1.17

# --- Last-resort offline TTS (Windows SAPI5), bottom of the voice chain ----
pyttsx3>=2.90

# --- Egress gate Layer 2 NER. Without these the privacy gate is weaker, ----
#     which is exactly the thing not to ship quietly degraded.
presidio-analyzer>=2.2
presidio-anonymizer>=2.2

# --- Ed25519 attestation + source-trust federation -------------------------
pynacl>=1.5

# --- PDF text extraction ---------------------------------------------------
pdfplumber>=0.10

# --- Fill, sign and OCR PDFs (pyproject extra `documents`) -----------------
#     PyPDFForm (MIT) fills forms and stamps a signature image; pyHanko (MIT)
#     makes digital signatures; rapidocr-onnxruntime (Apache-2.0) reads
#     scanned pages locally with ONNX models bundled in its wheel, so nothing
#     is downloaded at runtime. It reuses the onnxruntime above and pulls
#     opencv-python, Shapely and pyclipper.
PyPDFForm>=5.6
pyHanko>=0.37
rapidocr-onnxruntime>=1.2.3

# --- Creative trimmings ----------------------------------------------------
imageio-ffmpeg>=0.5
mutagen>=1.47

# --- Context compression. Degrades to passthrough if absent. --------------
#
# NOTE 1: pinned to 0.38.0, which publishes a cp310-abi3 win_amd64 wheel
# carrying the native core (`headroom._core`). 0.20.15's wheel had no core,
# so it installed cleanly and compressed nothing. The wrapper now reports a
# missing core as "unavailable" with the reason instead.
#
# NOTE 2, and this one matters: the repo used to pin `headroom-ai[all]`. On a real
# install, measured on Windows 11, that [all] extra pulls in
#
#   torch (490 MB on disk), transformers, sentence-transformers, datasets,
#   scikit-learn, scipy, pandas, pyarrow, opencv-python, rapidocr-onnxruntime,
#   litellm, openai, fastapi, uvicorn, starlette, mcp, magika, trafilatura,
#   and the whole tree-sitter-language-pack
#
# - about 2.3 GB, for an optional context-compression nicety that the app
# explicitly degrades past if it is absent. It also silently installed the
# ENTIRE memory tier, which made `-SkipMemory` skip nothing and made the
# "this adds about 2.5 GB" warning shown to the user simply untrue.
#
# So the installer takes the base package. Everything headroom actually needs
# for compression is in it; [all] is integrations with other tools. If you
# want the full extra, move this line to memory.txt where a 2 GB download is
# announced and consented to, rather than arriving inside "voice and PDF
# reading".
headroom-ai==0.38.0
