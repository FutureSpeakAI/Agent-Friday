# Keyboard shortcuts

These keys work across Agent Friday™. Press **?** to see the same list on
screen, or choose **Keyboard shortcuts** in the command palette (**Ctrl+K**).
The list on screen uses Friday's name as you gave it.

## Anywhere

| Keys | What it does |
|---|---|
| **Ctrl+K** | The command palette: a workspace, a panel or an action |
| **Ctrl+/** | Type to Friday: the chat field, brought back if it was hidden |
| **Ctrl+Shift+Space** | Talk to Friday, or stop talking |
| **Esc** | Interrupt Friday mid-sentence; close a menu, a panel or this list |
| **?** | This list |

## Windows and the chat tray

| Keys | What it does | In a workspace's own tab |
|---|---|---|
| **Ctrl+Alt+C** | Hide or show the chat tray | The same |
| **Ctrl+Shift+F** | Fullscreen with the chat beside it, or back | The same |
| **Ctrl+Alt+←** / **Ctrl+Alt+→** | Snap the window in front to that side: a half, then two thirds, then a third. With no window in front, they move the chat tray | Put the chat tray on that side: a third, then a half, then two thirds |
| **Ctrl+Alt+↑** | The window in front fills the screen; with none in front, the chat tray shows | Show the chat tray |
| **Ctrl+Alt+↓** | Free the window in front; with none in front, the chat tray hides | Hide the chat tray |

With no window in front, the Ctrl+Alt arrow keys act on the chat tray instead.
**←** and **→** move it to that side, **↑** shows it and **↓** hides it.

## In a chat box

| Keys | What it does |
|---|---|
| **Enter** | Send |
| **Shift+Enter** | A new line |

## On the desktop

These keys work on the desktop only, not in a workspace's own tab.

| Keys | What it does |
|---|---|
| **Ctrl+click** | A workspace in the dock opens in its own tab |
| **←** / **→** | The scene's previous or next structure, while no workspace is open |
| **F9** | The widget: a small window that is mostly Friday; F9 again to come back |

A middle-click on a dock button also opens that workspace in its own tab. Both
open the tab in the background, so you stay where you are. Settings never
opens in a tab of its own. If the browser blocks the tab, Friday asks you to allow pop-ups
for its address.

See [The holographic desktop](desktop.md) for the structures and the widget.

## Safety

| Keys | What it does |
|---|---|
| **Ctrl+Shift+Q** | Stop computer control now, and take back its permission |

## Anywhere in Windows

| Keys | What it does |
|---|---|
| **Alt+T** (hold) | Hold, speak and let go: what you said is typed into the window you were in |

This is Push-to-transcribe. It works in any Windows app, not just in Friday. If
you choose another key in **Settings > Voice**, the list shows that key. If
Push-to-transcribe is off, the list says so. See
[Voice](voice.md#push-to-transcribe-altt).

## Keys inside Mail and the 3D views

Mail and the 3D views have keys of their own: press **?** inside them.
