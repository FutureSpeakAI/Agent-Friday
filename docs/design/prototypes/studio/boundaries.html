The rules, in four lines

  1. A routine episode (origin: routine) belongs to its News run and to its show's shelf in News.
  2. A user episode (origin: user) belongs to the Studio Library, whichever surface asked for it: Create, chat, voice, or Send to.
  3. Studio search can find a routine episode; the result opens News. News never lists user episodes.
  4. One mini player, global; one /api/podcasts; the routine filter it already has is the line between the two.
