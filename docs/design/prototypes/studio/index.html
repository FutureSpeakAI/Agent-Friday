One Studio for everything she makes

Six clickable screens for the spec. They are drawings that move, not product code: nothing here talks to a server, every item and number is illustrative, and the names are synthetic. Keyboard works on every screen. The top bar and chat tray are the unified shell's, drawn to its rules.

  1. Library

    One library across every medium: search, filters by type, source and privacy, grid, list and the 3D view, a details rail with the same actions everywhere. Replaces Gallery, the Podcasts list and the Files 3D silo.

    Library
  2. Create

    One door. Say what you want; the right tool opens underneath, already filled in, with the model, cost and egress disclosed before it runs. Replaces Generate, the prompt bar, Music, Timeline and Make a podcast as separate screens.

    Create
  3. Viewer

    One frame for every medium: the stage changes, the credentials, privacy, relationships and actions do not. Image, podcast, video, deck, document, chart, 3D, page, code.

    Viewer
  4. Actions

    The same verbs on every item, and what "make a podcast of it" means for each medium. Publish always asks, in amber, because it leaves this computer.

    Actions
  5. Studio · News

    Where a podcast lives: the four News shows in News, on their runs; anything from any sources in Studio; one mini player; search finds across the line and links, never copies.

    Boundaries
  6. In the shell

    Studio inside the unified shell: the one top bar, the chat tray docked beside it, fullscreen with chat on Ctrl+Shift+F, and a live measure showing the workspace filling its frame.

    Shell

Brand: the --fr-* tokens from BRAND.md; Inter for text, Orbitron for labels only, JetBrains Mono for data; amber only where something needs you; status never by colour alone. Agent Friday™ by FutureSpeak.AI™.
