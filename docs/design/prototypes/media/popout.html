How a pop-out works, in the shell's terms

Own Chrome tab

The workspace, or one card, opens at /w/media?card=…. The shell renders its one top bar, the chat tray and fullscreen-with-chat exactly as in the desktop; the tab title is "Media · Agent Friday™".

Floating window

On the desktop the same card is a window (FWin), which maximizes to the tray's edge. "Own tab" on a window moves it to a tab; the lockup brings you back.

What travels

The card id and the view. Nothing else is in the URL: no titles, no text. The tab asks the index for the rest, so a private card never sits in a browser history line.
