# ── OPTIONAL: Layer 2 of the sensitivity classifier (Presidio NER) ────────────
# NOT installed by default, and deliberately so. sensitivity_classifier.py has
# always contained a complete Presidio integration (_load_presidio /
# _presidio_tier), but `presidio-analyzer` was never listed here, so the layer
# has never run in any environment - while the module docstring described a
# "four layer" defence. The code was real; the packaging was not.
#
# Measured cost (2026-08-24, this machine):
#   presidio-analyzer + spaCy + 16 transitive deps ... ~47 MB of wheels
#   spaCy English model (en_core_web_lg)            ... ~590 MB   (sm: ~12 MB)
#   torch required?                                 ... NO - unlike Layer 3
#
# Presidio's PERSON / LOCATION / DATE_TIME recognisers fire on ordinary prose,
# and this codebase has three scars from over-broad classification already. So
# it ships OFF, and even when installed it only OBSERVES:
#
#   FRIDAY_PRESIDIO_SHADOW=1    log what it WOULD flag, change no outcomes
#   FRIDAY_PRESIDIO_ENFORCE=1   let it affect decisions (do not set until the
#                               shadow log has been reviewed - see
#                               services/presidio_shadow.py::summarize)
#
# To enable observation:
#   pip install presidio-analyzer
#   python -m spacy download en_core_web_lg     # or en_core_web_sm to save ~578 MB
#
